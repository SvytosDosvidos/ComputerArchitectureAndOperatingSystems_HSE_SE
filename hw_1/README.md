# ИДЗ №1: Морской бой автономных кораблей (Вариант 22)
**НИУ ВШЭ, Факультет компьютерных наук, Программная инженерия**  
**Дисциплина:** Архитектура компьютера и операционные системы (АКОС)

Консольное приложение на языке C для ОС Linux, моделирующее последовательную имитацию боя двух автономных флотов с использованием низкоуровневых системных вызовов POSIX и дескрипторов файлов (`dprintf`, `open`, `read`, `write`, `close`, `sigaction`).

---

## 1. Системные требования

Для запуска и сборки на вашем ноутбуке необходимы:
- **ОС:** Linux (Ubuntu, Debian, Fedora, Arch и др.), либо **WSL / WSL2** в Windows, либо **macOS**
- **Компилятор:** `gcc` (версия 9+) или `clang`
- **Утилиты сборки:** `make` (или `cmake` версии 3.10+)

Установка необходимых пакетов в Ubuntu / Debian:
```bash
sudo apt update
sudo apt install -y build-essential make gcc
```

## 2. Быстрый старт (Сборка и запуск)

### Вариант А: Сборка через `make` (рекомендуется)

1. Перейдите в каталог проекта:
```bash
cd c-naval-battle
```

2. Соберите проект:
```bash
make all
```
*Исполняемый файл будет скомпилирован в `bin/naval_battle` без предупреждений (`-Wall -Wextra -pedantic -std=c11 -O2`).*

3. Запустите симуляцию с наглядной задержкой между раундами:
```bash
./bin/naval_battle --delay 250
```

4. Запустите автоматические тесты (проверяют сборку, воспроизводимость seed, чтение конфигов и перехват SIGINT):
```bash
make test
```

---

### Вариант Б: Сборка через `cmake`

```bash
cd c-naval-battle
mkdir -p build && cd build
cmake ..
cmake --build .
./bin/naval_battle --delay 250
```

## 3. Параметры командной строки

```bash
./bin/naval_battle [опции]
```

| Параметр | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `-c, --config <file>` | Загрузить параметры из файла конфигурации | — |
| `-w, --width <int>` | Ширина морских полей (от 5 до 30) | `10` |
| `-h, --height <int>` | Высота морских полей (от 5 до 30) | `10` |
| `-r, --rounds <int>` | Предельное число раундов боя | `100` |
| `-d, --delay <ms>` | Задержка отображения шагов в миллисекундах | `250` |
| `-s, --seed <uint>` | Фиксированное начальное число ГСЧ (для воспроизводимости) | Текущее время |
| `-l, --log <file>` | Имя файла для записи журнала протокола | `battle_report.log` |
| `--rule <alive\|fixed1\|max2>` | Правило выстрелов: по живым палубам (`alive`), 1 выстрел (`fixed1`), максимум 2 (`max2`) | `alive` |
| `--coord-a <none\|deconflict>` | Режим командного центра Флота А (`deconflict` — согласование целей) | `deconflict` |
| `--coord-b <none\|deconflict>` | Режим командного центра Флота Б (`none` — полная автономия) | `none` |
| `--strat-a <random\|hunt\|checker>` | Стратегия кораблей Флота А (`hunt` — охота, `checker` — шахматная, `random` — случайная) | `hunt` |
| `--strat-b <random\|hunt\|checker>` | Стратегия кораблей Флота Б | `random` |
| `--allow-repeat` | Разрешить повторные выстрелы по уже подбитым клеткам | Запрещено |
| `--hide-ships` | Включить «туман войны» (скрывать целые корабли противника) | Выключено |
| `--no-color` | Отключить ANSI-цвета в консоли | Цвета включены |
| `--help` | Показать подробную справку | — |

## 4. Примеры типовых запусков

### Наглядная демонстрация боя в реальном времени:
```bash
./bin/naval_battle --delay 300
```

### Воспроизводимый тест для отчета (фиксированный `seed`):
```bash
./bin/naval_battle --seed 12345 --rounds 40 --delay 0 -l report_run.log
```

### Запуск с готовым конфигурационным файлом:
```bash
./bin/naval_battle -c data/config_default.txt
```

### Быстрый бой на малом поле 7x7:
```bash
./bin/naval_battle -c data/config_small.txt --delay 100
```

### Проверка корректного прерывания (Ctrl+C):
Запустите симуляцию с большой задержкой:
```bash
./bin/naval_battle --delay 1000
```
Нажмите **Ctrl+C** в любой момент раунда. Программа перехватит сигнал `SIGINT` через системный обработчик `sigaction`, сохранит финальную статистику и лог на диск, закроет дескрипторы и корректно завершится.

```text
├── data/                    # Наборы тестовых конфигураций
│   ├── config_default.txt   # Стандартный бой 10x10

│   ├── config.h             # Парсинг параметров и файлов

├── src/                     # Исходный код реализации на C
│   ├── board.c
│   ├── config.c
│   ├── fleet.c
│   ├── judge.c
│   ├── logger.c
│   ├── main.c
│   └── ship.c
└── tests/
    └── run_tests.sh         # Скрипт автоматического тестирования
```

## 6. Очистка артефактов сборки

```bash
make clean
```
Удаляет каталог объектных файлов `build/`, бинарный файл `bin/` и созданные логи `*.log`.
